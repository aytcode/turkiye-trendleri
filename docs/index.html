Nasıl çalışır?

  1. Her gün GitHub Actions; Google Trends, YouTube, X ve TikTok'tan Türkiye trendlerinin anlık görüntüsünü alır.
  2. Her hafta anlık görüntüler birleştirilir, Vikipedi okunmaları ve Instagram hashtag etkileşimi eklenir.
  3. Platformlar arası eşleşen konular tek bir "Haftanın Konuları" listesinde puanlanır.
  4. Markdown + bu grafikli sayfa üretilir, depoya kaydedilir ve GitHub Pages'e yayınlanır.

Ham veriler JSON olarak açıktır: data/weeks.json

Veriler resmi API'lerden ve herkese açık akışlardan (Google Trends RSS, Wikimedia, YouTube Data API, X API, TikTok Research API, Instagram Graph API) haftalık olarak toplanır. Kod GitHub üzerinde, MIT lisansıyla. Platform adları ilgili sahiplerinin ticari markalarıdır; bu proje onlarla bağlantılı değildir.
